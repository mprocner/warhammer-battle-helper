# Description
I want to implement images files management feature in application.
It should be located in Options panel as a separate tab called "Files". Create new file FilesTab.jsx for it.
Tab should be only visible to GameMaster (GM).
GameMaster (GM) should be able to upload images to the files repository and delete them.
Only images files are supported at the beginning.
Add possibility to upload multiple files at once.
GM could create file folders to organize files.
Files should be stored in the backend and associated with the user account.
In database save them in the user document under `files` field as an array.
Use similar visual design as in other parts of the application, following existing styles and themes.
