Approach 3 — Radial HUD · Token Editing Mockup

Warhammer Battle Helper · Static HTML
Concept: Everything is anchored to the token — no popover, no modal. Up to 8 state slots arranged in a ring at 45° intervals. On non-selected tokens: only active state badges are visible at their ring positions (ring fills organically as states are added). On token selection: the full 8-slot ring appears (active = lit badge, empty = ghost "+" slot), the thin HP bar expands into an inline interactive row with +/− buttons, and stat chips appear below the token.

Trade-off: Maximum speed in combat — one click on a slot removes a condition, one click on "+" adds one from a mini-palette, HP can be adjusted with a single tap. Zero context switching. Risk: on dense grids, rings of nearby tokens can overlap. Mitigated by z-index (selected token always on top) and a subtle dimming of non-selected tokens' rings near the active one.

Ghost "+" slots → state palette
Overlap on dense grids
Selected token: z-index elevated, ring fully visible.

Neighbouring tokens: ring opacity reduced to 30% via CSS class .tok--neighbour while a token is selected.
Ring slots (8, fixed at 45°): Slots are positionally stable — once assigned, a state always appears at the same slot. Assignment order: first-in-first-placed, lowest slot index first. States keep their slot on deselect/reselect.
Non-selected token: Only active state badges render at their slot positions. No ghost slots, no dashed ring guide. HP bar (thin, 7px) always visible when wounds or any condition is active.
Selected token — ring edit mode: Full 8-slot ring revealed. Active = glowing badge. Empty = ghost "+" circle. Click active slot to remove condition (decrement level; removes at 0). Click "+" to open state palette.
Interactive HP row: Replaces thin bar. Two tap-targets (+/−) flank a larger bar. The bar text updates live. Long-press on the bar opens a number input for direct entry (touch-friendly).
Stat chips row: Always shows 5 configurable stat chips below the ring (defined per system). Tap chip value to inline-edit. Chips use a frosted-glass background so they're readable over varied grid tiles.
Overlap mitigation: z-index 100 on selected token group vs z-index 10 on others. Non-selected token state badges fade to 30% opacity while any token is selected. For very dense grids, combine with Approach 2 modal as fallback full editor.
