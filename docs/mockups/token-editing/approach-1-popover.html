Approach 1 — Popover · Token Editing Mockup

Warhammer Battle Helper · Static HTML
Concept: Clicking a token opens a contextual popover anchored to its right side with a left-pointing arrow. The popover contains: HP management (+/- bar), a full state palette (toggle on/off, level on active states), and compact stat chips. Active states are always visible as small radial badges around the token — even when unselected. The HP bar appears above any damaged token regardless of selection.

Trade-off: Doesn't block the map tile under the token. Limited space (≈240px width) — secondary stats may need a scrollable area. State palette inside the popover means all state management is in one place but the panel can feel dense.

HP bar (always-on): Visible above any token with wounds or active conditions — not only selected tokens. Fill: green >50%, orange 20–50%, red <20% of max HP. Hides when HP is full and no conditions are active.
Active state badges (always-on): Only active states are rendered as radial badges; up to 8 can be distributed around the token ring. States without a level show no counter. Right-click badge to increment level; badge disappears when removed.
Popover arrow: Points left toward the token. Popover opens to the right so the grid tile under the token stays visible. If token is near the right viewport edge, popover flips left.
Condition palette in popover: Rows of all states from the active game system. Inactive = greyscale 42%. Active = golden glow. Click to toggle; right-click to increase level. Available states are system-defined, not hardcoded.
Avatar tokens: Circular photo placeholder (shows initials when no image uploaded). Gold border — no ally/enemy color coding at token level. Teams/factions expressed differently (e.g., initiative order, sidebar grouping).
Icon note: All emojis are mockup placeholders. Real implementation uses @mui/icons-material: Sick, Bloodtype, VisibilityOff, Shield, SlowMotionVideo, AutoAwesome, Bedtime, LocalFireDepartment, ElectricBolt, etc.
